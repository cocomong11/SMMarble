# SMMarble 🎲

**C언어로 구현한 '숙명 모두의마블' 보드게임 시뮬레이터**

각 플레이어가 에너지를 관리하며 전공 수업을 수강해 졸업 학점(30학점)을 먼저 채우는 것을 목표로 하는 콘솔 기반 보드게임입니다. 보드·음식카드·축제카드 구성을 외부 설정 파일에서 읽어 들여, 칸 수나 카드 내용이 바뀌어도 코드 수정 없이 동작하도록 설계했습니다.

> 전자공학도를 위한 프로그래밍 기초 기말 프로젝트 (2025). 제공된 base code 구조(`smm_database.c`, 헤더) 위에서 `smm_object.c`와 `main.c`를 구현했습니다.

<br>

## 🎯 게임 규칙

- 플레이어는 주사위(1~6)를 굴려 보드를 순환하며 이동합니다.
- 시작 시 에너지는 **집 노드의 보충 에너지**로 초기화되고, 집을 지날 때마다 에너지가 충전됩니다.
- 멈춘 칸의 유형에 따라 서로 다른 동작을 수행합니다.
- **한 명이라도 `GRADUATE_CREDIT`(30학점) 이상을 이수하고 집에 도착하면 게임이 즉시 종료**되며, 졸업 플레이어가 수강한 강의의 이름·학점·성적을 출력합니다.

### 노드(칸) 유형

| 유형 | 동작 |
|------|------|
| 강의 | 에너지가 충분하고 미수강 강의면 수강/드랍 선택. 수강 시 성적(A+~F)이 랜덤 부여 |
| 식당 | 지정된 보충 에너지만큼 충전 |
| 실험실 | 실험중 상태일 때 주사위를 굴려 성공 기준값 이상이면 실험 종료(시도마다 에너지 소모, 음수 가능) |
| 집 | 시작/종료점. 지날 때마다 에너지 충전 |
| 실험 | 실험중 상태로 전환되며 실험실로 이동 |
| 보충찬스 | 음식카드를 랜덤으로 뽑아 에너지 충전 |
| 축제 | 축제카드를 랜덤으로 뽑아 미션 수행 |

<br>

## 🧩 설계 포인트

- **데이터 캡슐화 (Data Encapsulation)**: 게임 객체(노드·음식카드·축제카드·수강 이력)를 하나의 구조체 형태로 표현하고, 구조체 정의와 접근은 `smm_object.c` 내부로 한정했습니다.
- **모듈 간 경계 분리**: 파일 간 전역 변수 공유(`extern`)를 사용하지 않고, linked list는 `smm_database.c` 내부에서만 접근하며 다른 파일은 `smm_database.h`에 선언된 함수를 통해서만 데이터에 접근합니다.
- **입출력 책임 분리**: 표준 입출력(키보드·모니터)은 `main.c`에서만 처리합니다.
- **가변 구성 파싱**: 보드/카드 개수를 고정하지 않고 설정 파일의 줄 수에 따라 동적으로 인식합니다.
- **예외 상황 처리**: 실험 실패 반복, 에너지가 음수가 되는 경우 등 규칙상 발생 가능한 경계 상황을 명세대로 처리합니다.

<br>

## 📁 파일 구조

```
SMMarble/
├── main.c                     # 플레이어 관리 및 게임 흐름 (파일 파싱·턴 진행·종료 판정)
├── smm_object.c               # 게임 객체 구조체 정의 및 객체 조작 함수
├── smm_object.h               # 객체 관련 상수(노드 유형·성적)와 함수 프로토타입
├── smm_database.c             # 노드·카드·수강 이력을 저장하는 linked list DB (base code)
├── smm_database.h             # DB 접근 함수 프로토타입
├── smm_common.h               # 공통 상수 (GRADUATE_CREDIT, MAX_DIE, MAX_PLAYER 등)
├── marbleBoardConfig.txt      # 보드 노드 구성 (노드 이름 / 유형 / 학점 / 소요·보충 에너지)
├── marbleFoodConfig.txt       # 음식카드 구성 (음식 이름 / 보충 에너지)
├── marbleFestivalConfig.txt   # 축제카드 구성 (미션 문자열)
└── Makefile.win               # 빌드 설정
```

### 주요 상수 (`smm_common.h`)

| 상수 | 값 | 의미 |
|------|-----|------|
| `GRADUATE_CREDIT` | 30 | 졸업에 필요한 학점 |
| `MAX_DIE` | 6 | 주사위 최대 눈 |
| `MAX_PLAYER` | 10 | 최대 플레이어 수 |

<br>

## ⚙️ 빌드 & 실행

```bash
# gcc 사용 시
gcc main.c smm_object.c smm_database.c -o SMMarble
./SMMarble
```

실행하면 플레이어 수와 각 플레이어의 이름을 입력받고, 매 턴마다 모든 플레이어의 상태(위치, 실험중 여부, 누적 학점, 현재 에너지)를 출력하며 게임이 진행됩니다.

> 설정 파일(`marble*.txt`)은 실행 파일과 같은 디렉터리에 있어야 합니다. 내용을 바꾸면 보드 구성·카드가 그에 맞게 재구성됩니다.

<br>

## 🛠️ 기술 스택

`C` · 구조체 · 포인터 · Linked List · 파일 입출력 · Data Encapsulation

<br>

## 👤 구현 범위

`smm_object.c`(객체 구조체 정의 및 조작 함수)와 `main.c`(파일 파싱, 플레이어 설정, 게임 흐름 전체)를 직접 구현했습니다. `smm_database.c`는 제공된 base code를 활용했습니다.
